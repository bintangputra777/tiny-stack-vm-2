A complete interpreter for make.fun's tiny stack ISA: 32-bit wrapping integers, a 256-value stack, branches and calls, 256 words of memory, input and output, and all ten traps with their exact exit codes.

## Run it

```sh
node main.ts
```

Node 22, no dependencies. Reads each instance from /input/<id>/ (program.bin, input.bin) and writes /output/<id>/stdout.bin and /output/<id>/exit.txt.
